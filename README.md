# 暑假作业小管家

给小朋友的暑假作业计划小工具：每天自动算出要写多少作业，可以自己选休息日、临时请假、手动调整今天的任务量，写完打卡并记录时间。手机装上 PWA 后像普通 App 一样使用，电脑关机也能用；手机和电脑通过 GitHub 云端自动同步。

## 功能

- 每日作业自动拆分：开学日倒推，每天目标随打卡情况自动重算
- 休息日自由选择，今日可一键临时请假 / 改回写作业日
- 每科可手动微调今日目标（− / ＋）
- 每次打卡记录时间，如「⏰ 14:32 写了 2 页」
- 日历视图、进度统计、最近记录
- 云端同步：手机和电脑在任何网络下自动同步；离线各自保存、恢复后自动合并，打卡记录永不丢失
- PWA：Android 手机 Chrome 可「添加到主屏幕」安装，离线可用

## 手机上安装（推荐）

1. 手机 Chrome 打开：<https://bug3260.github.io/homework-planner/>
2. 右上角菜单 → 「添加到主屏幕 / 安装应用」
3. 之后就像普通 App：桌面图标、全屏打开、没网也能用、电脑关机也能用

## 云端同步（一次设置，之后全自动）

手机和电脑都把数据放进你自己的 GitHub 私密仓库（Gist），任何网络下自动同步，电脑不需要开机。

1. 创建 GitHub 令牌（在电脑上做一次）：
   - github.com 登录 → 右上角头像 → Settings → Developer settings → Fine-grained personal access tokens → Generate new token
   - Expiration 选 1 年；Permissions → Account permissions → Gists → Read and write → Generate token
   - 复制 github_pat_ 开头的那串令牌（只显示一次）
2. 电脑：双击「暑假作业小管家.html」→ 设置 → ☁️ 云端同步 → 粘贴令牌 → 「🔗 连接云端」
3. 手机：打开 App → 设置 → ☁️ 云端同步 → 粘贴同一个令牌 → 「🔗 连接云端」
4. 之后两边任何网络下 20 秒内自动同步；断网时先存本机，恢复后自动合并

连接时会自动找到并复用已有的数据仓库：多台设备共用同一个 Gist，不会各建各的。
设置页会显示「数据仓库 xxxxxxxx…」，两台设备前 8 位一致即同一个仓库。

> 令牌只保存在你的浏览器本地，不会上传到本仓库。私密 Gist 只有持令牌者能读写。

### 旧数据搬家（第一次开启云同步前做一次）

重要：先让电脑版连接云端，再让手机连接。

1. 电脑双击「启动本地服务器.bat」并保持窗口开着
2. 手机打开旧局域网网址（http://192.168.x.x:8000），等到页面顶部显示「☁️ 已同步」（把手机数据先同步到电脑）
3. 按上面步骤：先给电脑版连云端，再给手机 App 连云端
4. 连好后手机数据全部保留，旧局域网网址可以不再使用

## 局域网同步（备用）

电脑双击 启动本地服务器.bat 后，手机打开窗口里显示的 http://192.168.x.x:8000 也能同步，功能同以前；一般用上面的云端同步即可。

## 文件说明

- index.html / manifest.webmanifest / sw.js / icon-*.png — PWA 主程序（GitHub Pages 托管的就是它）
- 暑假作业小管家.html — 单机文件版，电脑上双击即可使用
- server.py — 局域网同步服务器（备用），数据存在 data.json（首次运行自动生成，不入库）
- 启动本地服务器.bat / start_server.ps1 — Windows 一键启动局域网服务器（自动放行防火墙）
- make_icons.py — 用 Pillow 重新生成图标：python make_icons.py
- 使用说明.txt — 完整中文使用说明

## 重要提醒

- 换手机 / 清浏览器数据后：重装 App 并重新粘贴令牌，数据会从云端自动恢复
- PWA 更新后手机可能还是旧版，再刷新一次就是新版（共刷新两次）
- 想从头开始：设置 → 清空所有数据（会同步清空云端）
- 若设备间「数据仓库」编号不一致：每台设备重新点一次「🔗 连接云端」即可统一；每次打开 App 也会自动对齐，打卡记录按并集合并、不会丢
- 数据只存在浏览器本地和你的私密 Gist 里，不经过其他服务器
