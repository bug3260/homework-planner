# 暑假作业小管家

给小朋友的暑假作业计划小工具：每天自动算出要写多少作业，可以自己选休息日、临时请假、手动调整今天的任务量，写完打卡。支持手机和电脑在同一 WiFi 下自动同步，离线时各自保存、重连后自动合并。

## 功能

- 每日作业自动拆分：开学日倒推，每天目标随打卡情况自动重算
- 休息日自由选择，今日可一键临时请假 / 改回写作业日
- 每科可手动微调今日目标（− / ＋）
- 每次打卡记录时间，如「⏰ 14:32 写了 2 页」
- 日历视图、进度统计、最近记录
- 手机和电脑局域网自动同步（打卡记录永不丢失，见下方「同步」）
- PWA：Android 手机 Chrome 可「添加到主屏幕」安装，离线可用

## 文件说明

- index.html / manifest.webmanifest / sw.js / icon-*.png — PWA 主程序（GitHub Pages 托管的就是它）
- 暑假作业小管家.html — 单机文件版，电脑上双击即可使用（本地使用时自动连局域网同步）
- server.py — 局域网同步服务器（GET/PUT /api/state），数据存在 data.json（首次运行自动生成，不入库）
- 启动本地服务器.bat / start_server.ps1 — Windows 一键启动服务器（自动放行防火墙）
- make_icons.py — 用 Pillow 重新生成图标：python make_icons.py

## 手机上安装（推荐）

1. 手机 Chrome 打开：<https://bug3260.github.io/homework-planner/>
2. 右上角菜单 → 「添加到主屏幕 / 安装应用」
3. 之后就像普通 App：桌面图标、全屏打开、没网也能用

> 托管版的数据只存在各自浏览器的本机里，不同网址之间不互通。

## 手机和电脑同步（同一 WiFi）

1. 电脑上双击 启动本地服务器.bat，保持窗口开着
2. 手机 Chrome 打开窗口里显示的绿色局域网网址（如 http://192.168.x.x:8000，要带 http://）
3. 电脑自己用：双击 暑假作业小管家.html，或打开 http://127.0.0.1:8000
4. 两边自动互通：一边打卡，另一边 20 秒内能看到（切回前台会立即同步一次）

- 手机不连电脑时照常用，记录先存在手机里；重连后自动合并，两边新增的打卡都会保留
- 设置类内容（作业、休息日、每日目标）若两边同时改过，以最后同步上来的一边为准
- 「清空所有数据」会把另一台也一起清空（同步后生效）
- 第一次正式使用建议：两边都点一次「设置 → 清空所有数据」再重新填写

### 手机打不开时按顺序检查

1. 手机和电脑要连同一个 WiFi；路由器若开了「AP 隔离」或「访客网络」，两边互相看不到
2. 防火墙：右键 启动本地服务器.bat →「以管理员身份运行」自动放行 8000 端口
3. 网址以电脑窗口里显示的绿色网址为准
4. 提示端口被占用：关掉之前留下的黑色窗口再重新双击

## 重要提醒

- 数据保存在各自浏览器的本地存储里；换网址、清浏览器数据后需重新填写
- PWA 更新后手机可能还是旧版，再刷新一次就是新版（共刷新两次）
- GitHub Pages 是静态托管，没有 /api/state 同步接口；需要跨设备同步请用上面的局域网方式
- 想从头开始：设置 → 清空所有数据
