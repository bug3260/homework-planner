📚 暑假作业小管家 · 使用说明
========================================

【一、这是什么】
一个给小朋友的暑假作业计划小工具：每天自动算出要写多少作业，
可以自己选休息日、临时请假、手动调整今天的任务量，写完打卡。
数据只保存在打开它的那个浏览器里，不需要注册账号。

【二、电脑上怎么用（最简单）】
双击「暑假作业小管家.html」就能用。

【三、手机上怎么用（Android 手机 + Chrome）】
推荐方式：把本文件夹上传到免费静态托管网站，获得一个 https 网址。
- GitHub Pages / Netlify / Gitee Pages 都可以（网上搜一下教程，几分钟搞定）。
- 手机 Chrome 打开网址 → 右上角菜单 → 「添加到主屏幕 / 安装应用」。
- 装好后就像普通 App：桌面图标、全屏打开、没网也能用。

不注册账号的临时方式（手机和电脑连同一个 WiFi）：
- 电脑上双击「启动本地服务器.bat」，把窗口里绿色的网址输入手机 Chrome。
  例如 http://192.168.x.x:8000（要输 http:// 开头，不是 https）。
- 电脑自己看可以用：http://127.0.0.1:8000
- 注意：功能都能用，但受浏览器限制，不能离线、不能装成 App。
- 手机打不开时按顺序检查：
  1) 手机和电脑要连同一个 WiFi；路由器若开了「AP 隔离」或「访客网络」，手机和电脑互相看不到。
  2) 防火墙没放行：右键「启动本地服务器.bat」→「以管理员身份运行」，脚本会自动放行 8000 端口；
     或在防火墙弹窗里勾选「专用网络」并点「允许访问」。
  3) 网址输错：以电脑窗口里显示的绿色网址为准。
  4) 提示「端口已被占用」：关掉之前留下的黑色小窗口，再重新双击。
- 不用时按 Ctrl+C 结束，或直接关掉窗口。

【四、重要提醒】
- 数据只存在打开它的那个浏览器里：换网址、换手机或清除浏览器数据后，需要在「设置」里重新填一次。
- 更新 App 后，手机第一次打开可能还是旧版本，再刷新一次就是新版（共刷新两次）。
- 想从头开始，在「设置」最下面点「清空所有数据」。

【六、手机和电脑怎么同步】
- 前提：手机和电脑连同一个 WiFi，电脑上双击「启动本地服务器.bat」并保持窗口开着。
- 之后两边自动互通：一边打卡，另一边 20 秒内就能看到（切回前台会立即同步一次）。
- 手机不连电脑时照常用，记录先存在手机里；重新连上后自动合并，两边新增的打卡都会保留。
- 设置类内容（作业、休息日、每日目标）如果两边同时改过，以最后同步上来的一边为准。
- 「清空所有数据」会把另一台也一起清空（等它同步后生效）。
- 第一次正式使用建议：在手机和电脑上都点「设置 → 清空所有数据」一次再重新填写；之后只需在一边填写。
- 电脑双击「暑假作业小管家.html」或打开 http://127.0.0.1:8000（先启动 bat）都会自动同步。
- 托管到 https 网址的版本没有同步服务，数据各存各的；要同步请用局域网方式。
- 每次打卡都会记录时间（例如 14:32 写了 2 页），在「今日计划」科目卡片和「我的进度 → 最近记录」里能看到。

【五、图标】
图标由 make_icons.py 自动生成（需要电脑装有 Python 和 Pillow）。
想换颜色或图案，修改脚本后运行：python make_icons.py
