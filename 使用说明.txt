📚 暑假作业小管家 · 使用说明
========================================

【一、这是什么】
给小朋友的暑假作业计划小工具：每天自动算出要写多少作业，
可以自己选休息日、临时请假、手动调整今天的任务量，写完打卡并记录时间。
数据保存在本机浏览器里；开启云端同步后，手机和电脑自动互通。

【二、手机上怎么装（推荐，Android 手机 + Chrome）】
1. 手机 Chrome 打开：https://bug3260.github.io/homework-planner/
2. 右上角菜单（⋮）→「添加到主屏幕 / 安装应用」。
3. 装好后就像普通 App：桌面图标、全屏打开、没网也能用、电脑关机也能用。

【三、电脑上怎么用】
双击「暑假作业小管家.html」就能用。

【四、云端同步（一次设置，之后全自动）】
电脑和手机的数据都放进你自己的 GitHub 私密仓库（Gist），
任何网络下自动同步，电脑不需要开机。两台设备用同一个令牌。

① 创建 GitHub 令牌（在电脑上做一次即可）：
   - 打开 github.com 并登录
   - 右上角头像 → Settings → 最下面 Developer settings
   - Fine-grained personal access tokens → Generate new token
   - Token name 随便填；Expiration 选 1 年
   - Permissions → Account permissions → Gists → Read and write
   - Generate token → 复制 github_pat_ 开头的那串（只显示一次！）
② 电脑：双击「暑假作业小管家.html」→「设置」→「☁️ 云端同步」粘贴令牌
   →「🔗 连接云端」，看到 ✅ 即成功。
③ 手机：打开 App →「设置」→ 粘贴同一个令牌 →「🔗 连接云端」，看到 ✅ 即成功。
④ 之后：两边任何网络下 20 秒内自动同步；断网时先存本机，恢复后自动合并，
   打卡记录不会丢。

【五、旧数据搬家（第一次开启云同步前做一次）】
重要：一定让「电脑版先连云端、手机后连」，这样两边数据都保留。
1. 电脑双击「启动本地服务器.bat」并保持窗口开着。
2. 手机打开旧的局域网网址（http://192.168.x.x:8000），等到页面顶部显示
   「☁️ 已同步」。（这一步把手机里的数据同步到电脑。）
3. 按【四】的步骤：先给电脑版连云端，再给手机 App（Pages 版）连云端。
4. 连好后手机数据全部保留，旧局域网网址可以不再使用。

【六、局域网同步（备用）】
电脑双击「启动本地服务器.bat」后，手机打开窗口里显示的绿色网址
（如 http://192.168.x.x:8000）也能同步，功能和以前一样；一般用【四】即可。
手机打不开时按顺序检查：
  1) 手机和电脑要连同一个 WiFi；路由器若开了「AP 隔离」或「访客网络」，互相看不到。
  2) 防火墙没放行：右键「启动本地服务器.bat」→「以管理员身份运行」。
  3) 网址输错：以电脑窗口里显示的绿色网址为准。
  4) 提示「端口已被占用」：关掉之前留下的黑色小窗口，再重新双击。

【七、重要提醒】
- 换手机 / 清除浏览器数据后：重装 App 并重新粘贴令牌，数据会从云端自动恢复。
- 令牌只保存在你的浏览器里：不要发到聊天群、不要写进文件上传到网上。
- 想从头开始：在「设置」最下面点「清空所有数据」（会同步清空云端）。
- 更新 App 后，手机第一次打开可能还是旧版本，再刷新一次就是新版（共刷新两次）。
- 云端同步走 GitHub 官方接口，正常使用完全够用。
